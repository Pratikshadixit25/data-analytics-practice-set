### Day 4: DAX Practice — Hospital Billing Analysis

**Dataset:** Hospital Billing Data

Completed a 34-question practical exercise covering DAX measures, calculated columns, and filter-based calculations.

Topics covered:
- Aggregation functions: `SUM`, `AVERAGE`, `MIN`, `MAX`
- Counting functions: `COUNTROWS`, `DISTINCTCOUNT`, `COUNTA`, `COUNTBLANK`
- Iterator function: `SUMX`
- Calculated columns for gross billing, discount, final bill, profit, and profit margin
- Conditional logic using `IF` and `ISBLANK`
- Filter functions: `CALCULATE`, `FILTER`, `ALL`, `ALLEXCEPT`, and `REMOVEFILTERS`
- Billing analysis by department, patient type, doctor, quantity, and discount
