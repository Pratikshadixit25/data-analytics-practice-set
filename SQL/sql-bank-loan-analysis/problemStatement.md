Problem Statement

A bank needs to maintain and analyze customer loan information using a MySQL database. The objective of this task is to create a Loan Management System to store customer and loan-related data and perform different SQL operations for data analysis.

The database contains information such as customer name, city, loan category, loan amount, interest rate, loan status, loan tenure, credit score, and application date.

The analysis includes:

Retrieving and filtering loan records
Using aggregate functions such as COUNT(), SUM(), AVG(), MAX(), and MIN()
Performing category-wise and city-wise analysis using GROUP BY
Filtering grouped results using HAVING
Sorting loan data using ORDER BY
Combining WHERE, GROUP BY, HAVING, and ORDER BY for loan analysis
