# SQL CRUD and Filtering Practice

This task demonstrates basic SQL operations and data filtering using MySQL.

## Tasks

### Read & Filter Data
1. Display all employees.
2. Display employee name, department, and salary.
3. Find employees working in the IT department.
4. Find employees with salary greater than 50,000.
5. Find employees from Pune.
6. Find employees with more than 3 years of experience.
7. Find employees with salary between 40,000 and 70,000.
8. Find employees belonging to IT or Finance.
9. Find employees whose names start with "A".
10. Display employees by salary in descending order.

### Update Data
1. Update the salary of a specific employee.
2. Increase the salary of IT employees by 10%.
3. Update an employee's city.
4. Change an employee's designation.
5. Update employees from Sales department to Marketing.

### Delete Data
1. Delete an employee using employee ID.
2. Delete employees with zero experience.
3. Delete employees from the HR department.
4. Delete employees based on city.

## Concepts Practiced

- Database and table creation
- Inserting multiple records
- SELECT queries
- WHERE clause
- BETWEEN operator
- OR operator
- LIKE operator
- ORDER BY
- UPDATE operations
- DELETE operations

## Dataset

An employee dataset containing information such as employee ID, name, department, designation, salary, city, and experience.

## Tools Used

- MySQL
- MySQL Workbench

## Purpose

The purpose of this task is to practice SQL CRUD operations and basic data retrieval and filtering techniques.
